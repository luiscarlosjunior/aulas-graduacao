# 📊 Ciência de Dados e Computação Científica

> Disciplinas focadas em análise de dados, métodos numéricos e computação científica aplicada

## 📚 Disciplinas

### [Ciência de Dados](ciencia-dados/)
Área focada em análise de dados, estatística e descoberta de conhecimento.

**🎯 O que você aprenderá:**
- **Análise de dados** com Python e bibliotecas especializadas (Pandas, NumPy)
- **Visualização de dados** e criação de gráficos
- **Estatística aplicada** para tomada de decisões
- **Processamento de dados** e limpeza de datasets
- **Pré-processamento** de dados para machine learning

**📁 Estrutura:**
- `python/` - Notebooks Jupyter com análises práticas
- `analise-dados/` - Projetos de análise exploratória

### [Métodos Numéricos](metodos-numericos/)
Disciplina que combina matemática e programação para resolver problemas científicos.

**🎯 O que você aprenderá:**
- **Algoritmos numéricos** para solução de equações
- **Análise de erros** em computação científica
- **Método dos Mínimos Quadrados** para ajuste de curvas
- **Implementação em Python** com NumPy e Matplotlib
- **Computação científica** aplicada

**📓 Notebooks disponíveis:**
- Introdução ao Python para Métodos Numéricos
- Noções de Erros e Propagação
- Método dos Mínimos Quadrados (MMQ)

## 🛠️ Ferramentas e Tecnologias

- **Python**: Linguagem principal para ciência de dados
- **Jupyter Notebook**: Ambiente interativo para análise
- **Pandas**: Manipulação e análise de dados
- **NumPy**: Computação numérica
- **Matplotlib**: Visualização de dados
- **Scikit-learn**: Machine learning (em projetos avançados)

## 🎯 Objetivos de Aprendizado

Ao completar este módulo, você será capaz de:
- Realizar análises exploratórias de dados
- Implementar algoritmos numéricos para problemas científicos
- Criar visualizações eficazes de dados
- Aplicar métodos estatísticos em problemas reais
- Desenvolver soluções de computação científica

## 📖 Como Estudar

### Para Ciência de Dados:
1. Configure o ambiente Python com Jupyter Notebook
2. Instale as bibliotecas necessárias: `pip install jupyter pandas numpy matplotlib`
3. Explore os notebooks de forma interativa
4. Pratique com datasets reais

### Para Métodos Numéricos:
1. Comece pela introdução ao Python
2. Estude os conceitos de erros numéricos
3. Implemente os algoritmos apresentados
4. Aplique em problemas práticos

## 📋 Pré-requisitos

- **Programação Python**: Conhecimento básico de Python
- **Matemática**: Álgebra linear e cálculo
- **Estatística**: Conceitos básicos de probabilidade e estatística
