# 🔧 Linguagem de Procedimento - PL/SQL

> Programação avançada em banco de dados Oracle

Esta área é dedicada ao estudo de linguagens procedurais em bancos de dados, com foco especial em PL/SQL (Procedural Language/SQL) da Oracle.

## 📚 O que é uma Linguagem de Procedimento?

Uma **linguagem de procedimento** em banco de dados é uma extensão do SQL que adiciona recursos de programação procedural, permitindo:

- ✅ Estruturas de controle (IF, WHILE, FOR)
- ✅ Tratamento de exceções
- ✅ Variáveis e tipos de dados complexos
- ✅ Procedures e functions
- ✅ Triggers automatizados
- ✅ Lógica de negócio no banco de dados

## ⚙️ Por que Usar Linguagens de Procedimento?

### Vantagens:
1. **Performance**: Lógica executada diretamente no servidor de banco de dados
2. **Segurança**: Encapsulamento de lógica de negócio
3. **Manutenção**: Código centralizado e reutilizável
4. **Integridade**: Triggers garantem regras de negócio
5. **Redução de Tráfego**: Menos comunicação cliente-servidor

### Casos de Uso Comuns:
- 📊 Processamento de dados em lote (batch)
- 🔒 Aplicação de regras de negócio complexas
- 🔄 Auditoria automática de alterações
- ⚡ Validações antes de inserir/atualizar dados
- 📧 Notificações e alertas automatizados
- 🧮 Cálculos complexos com múltiplas tabelas

## 🌐 Outros SGBDs

Embora este material foque em **PL/SQL (Oracle)**, os conceitos são aplicáveis a outros SGBDs:

| SGBD | Linguagem Procedural | Similaridade com PL/SQL |
|------|---------------------|------------------------|
| **PostgreSQL** | PL/pgSQL | 90% - Muito similar |
| **SQL Server** | T-SQL | 70% - Sintaxe diferente, conceitos similares |
| **MySQL** | Stored Procedures | 60% - Mais limitado |
| **DB2** | SQL PL | 80% - Similar ao PL/SQL |
