# Exercícios - Módulo 11: Relatórios com Operadores Aritméticos

## Exercício 1: Cálculos Básicos
Pratique operadores aritméticos (+, -, *, /) em consultas musicais.

## Exercício 2: Funções Matemáticas
Use ROUND, CEIL, FLOOR e outras funções em relatórios.

## Exercício 3: Relatórios Financeiros
Calcule receitas, royalties e métricas financeiras do streaming.

## Exercício 4: Análise Temporal
Implemente cálculos de tempo e durações musicais.

## Exercício 5: Expressões Condicionais
Combine CASE com operadores aritméticos para categorização.

As soluções detalhadas estão disponíveis no arquivo `solucoes.sql` nesta pasta.
