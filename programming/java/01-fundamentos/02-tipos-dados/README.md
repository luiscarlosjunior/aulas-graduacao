# Tipos de Dados em Java

Esta seção aborda os tipos de dados em Java, incluindo tipos primitivos, classes wrapper, declaração de variáveis e conversões.

## 🎯 Objetivos

- Compreender os tipos primitivos do Java
- Aprender sobre classes wrapper
- Entender conversões entre tipos
- Praticar declaração e uso de variáveis

## 📋 Conceitos Abordados

### Tipos Primitivos
- **byte**: 8 bits (-128 a 127)
- **short**: 16 bits (-32,768 a 32,767)
- **int**: 32 bits (-2³¹ a 2³¹-1)
- **long**: 64 bits (-2⁶³ a 2⁶³-1)
- **float**: 32 bits (precisão simples)
- **double**: 64 bits (precisão dupla)
- **char**: 16 bits (caractere Unicode)
- **boolean**: true ou false

### Classes Wrapper
- Byte, Short, Integer, Long
- Float, Double
- Character, Boolean

```bash

```

## 💡 Dicas Importantes

- Use `int` para números inteiros na maioria dos casos
- Use `double` para números decimais
- Use `final` para declarar constantes
- Nomes de variáveis devem ser descritivos
- Convenção camelCase para nomes de variáveis
