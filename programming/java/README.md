# Java Programming - Complete Learning Path

Este diretório contém uma coleção abrangente de exemplos e conceitos para aprender programação Java, organizados em uma progressão lógica de aprendizado.

## 📚 Estrutura do Curso

### 1. Fundamentos (`01-fundamentos/`)
- **Hello World**: Primeiro programa em Java
- **Tipos de Dados**: Primitivos, wrappers e conversões
- **Operadores**: Aritméticos, lógicos, relacionais e bitwise
- **Controle de Fluxo**: Condicionais e estruturas de repetição
- **Tratamento de Exceções**: Try-catch, finally e exceções customizadas

### 2. Programação Orientada a Objetos (`02-programacao-orientada-objetos/`)
- **Classes e Objetos**: Definição, instanciação e uso
- **Encapsulamento**: Modificadores de acesso e getters/setters
- **Herança**: Extensão de classes e reutilização de código
- **Polimorfismo**: Sobrescrita e sobrecarga de métodos
- **Interfaces**: Contratos e implementação múltipla
- **Classes Abstratas**: Classes base não instanciáveis

### 3. Conceitos Intermediários (`03-conceitos-intermediarios/`)
- **Collections**: List, Set, Map e suas implementações
- **Generics**: Tipos parametrizados e wildcards
- **Enumerações**: Tipos enum e suas funcionalidades
- **Annotations**: Metadados e reflection
- **Lambda e Streams**: Programação funcional em Java

### 4. Conceitos Avançados (`04-conceitos-avancados/`)
- **Reflection**: Introspecção e manipulação de classes
- **Concorrência**: Threads, synchronized, executors
- **I/O e NIO**: Manipulação de arquivos e streams
- **Networking**: Sockets e comunicação de rede
- **JVM e Memória**: Garbage collection e otimização

### 5. Design Patterns (`05-design-patterns/`)
- **Padrões Criacionais**: Singleton, Factory, Builder
- **Padrões Estruturais**: Adapter, Decorator, Facade
- **Padrões Comportamentais**: Observer, Strategy, Command

### 6. Frameworks e Bibliotecas (`06-frameworks-bibliotecas/`)
- **JUnit**: Testes unitários
- **Maven/Gradle**: Gerenciamento de dependências
- **Logging**: Log4j, SLF4J

### 7. Exercícios (`99-exercicios/`)
- Exercícios práticos organizados por nível de dificuldade

## 🚀 Como Usar

1. **Pré-requisitos**: Java 8+ instalado
2. **Compilação**: `javac NomeDoArquivo.java`
3. **Execução**: `java NomeDoArquivo`

Cada pasta contém seu próprio README.md com explicações detalhadas e instruções específicas.

## 📋 Objetivos de Aprendizado

Ao completar este curso, você será capaz de:
- ✅ Desenvolver aplicações Java robustas e bem estruturadas
- ✅ Aplicar princípios de POO e design patterns
- ✅ Utilizar collections e programação funcional
- ✅ Implementar concorrência e I/O eficientes
- ✅ Testar código com JUnit
- ✅ Gerenciar projetos com Maven/Gradle
