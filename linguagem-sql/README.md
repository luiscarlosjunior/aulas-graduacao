# Linguagem SQL - Curso Completo

Este diretório contém um curso completo de SQL estruturado de forma progressiva, do básico ao avançado, utilizando como exemplo prático um sistema similar ao Spotify.

## Estrutura do Curso

O curso está organizado em módulos sequenciais que devem ser estudados em ordem:

### Módulo 1: Fundamentos
- **01 - Introdução à Modelagem de Dados**: Conceitos básicos de modelagem e design de banco de dados
- **02 - Introdução à História SQL**: Evolução e importância da linguagem SQL
- **03 - Interface SQL Plus, Tabelas e Regras**: Primeiros passos com SQL

### Módulo 2: Estrutura de Dados
- **04 - Trabalhando com a Estrutura de Tabelas**: Criação e definição de tabelas
- **05 - Estrutura das Tabelas, Regras e Relacionamentos**: Constraints e relacionamentos
- **06 - Alteração de Estrutura de uma Tabela**: Comandos DDL para modificação

### Módulo 3: Manipulação de Dados
- **07 - Manipulação de Dados - Inserindo Dados (Parte I)**: Comandos INSERT básicos
- **08 - Manipulação de Dados - Inserindo Dados (Parte II)**: Comandos INSERT avançados
- **09 - Controle de Transações e Criação de Relatórios**: COMMIT, ROLLBACK e relatórios básicos

### Módulo 4: Consultas e Relatórios
- **10 - Relatórios com Filtros e Operadores**: WHERE, operadores relacionais e lógicos
- **11 - Relatórios com Operadores Aritméticos**: Cálculos e expressões
- **12 - Relatórios com Funções de Banco de Dados**: Funções agregadas e de string
- **13 - Relatórios com Subqueries**: Subconsultas e consultas aninhadas
- **14 - Relatórios com Múltiplas Tabelas**: JOINs e relacionamentos

### Módulo 5: Tópicos Avançados
- **15 - Operações com Conjuntos**: UNION, INTERSECT, EXCEPT
- **16 - Criando VIEWS**: Visões e consultas reutilizáveis

## Sistema Exemplo: MusiStream (Similar ao Spotify)

Durante todo o curso, utilizaremos como exemplo um sistema de streaming de música chamado **MusiStream**, que possui as seguintes características:

### Entidades Principais:
- **Usuários**: Informações dos usuários da plataforma
- **Artistas**: Dados dos artistas e bandas
- **Álbuns**: Coleções de músicas
- **Músicas**: Faixas individuais
- **Playlists**: Listas de reprodução criadas pelos usuários
- **Gêneros**: Categorias musicais
- **Assinaturas**: Planos de acesso à plataforma
- **Histórico de Reprodução**: Log de músicas tocadas

### Funcionalidades Abordadas:
- Cadastro de usuários e artistas
- Organização de músicas em álbuns
- Criação e gerenciamento de playlists
- Sistema de assinaturas
- Análise de dados de reprodução
- Relatórios de popularidade
- Recomendações baseadas em histórico
