# 🔄 Versionamento - Git e GitHub

> Guia completo sobre controle de versão com Git e colaboração usando GitHub

Este módulo oferece uma introdução abrangente ao Git e GitHub, cobrindo desde conceitos acadêmicos e históricos até práticas profissionais recomendadas pelas principais empresas de tecnologia.

## 📚 Conteúdo do Módulo

### 1️⃣ [Introdução Acadêmica sobre Git](01-introducao-academica.md)
Compreenda os fundamentos teóricos do controle de versão:
- O que é controle de versão e por que é importante
- Sistemas de controle de versão centralizados vs distribuídos
- Conceitos fundamentais: repositório, commit, branch, merge
- Benefícios acadêmicos e profissionais do Git

### 2️⃣ [História do Git](02-historia-git.md)
Conheça a origem e evolução do Git:
- Contexto histórico: desenvolvimento do kernel Linux
- Criação do Git por Linus Torvalds em 2005
- Evolução e adoção pela comunidade
- Git vs outros sistemas de controle de versão

### 3️⃣ [Como o Algoritmo do Git Funciona](03-algoritmo-git.md)
Explore os aspectos técnicos internos do Git:
- Estrutura de dados: objetos (blob, tree, commit, tag)
- Sistema de endereçamento com SHA-1
- Modelo de armazenamento e compressão
- Como o Git rastreia mudanças
- Grafo acíclico direcionado (DAG)

### 4️⃣ [Trabalhando com Git - Boas Práticas](04-trabalhando-com-git.md)
Aprenda metodologias profissionais segundo:
- **Microsoft**: GitHub Flow e práticas de pull requests
- **Google**: Code Review e padrões de commits
- **GitLab**: GitLab Flow e CI/CD integrado
- **Atlassian**: Estratégias avançadas de branching
- Mensagens de commit semânticas (Conventional Commits)

### 5️⃣ [Arquiteturas e Workflows Git](05-arquiteturas-git.md)
Domine diferentes estratégias de trabalho:
- **Git Flow**: para projetos com releases planejadas
- **GitHub Flow**: para desenvolvimento contínuo
- **GitLab Flow**: com ambientes de deploy
- **Trunk-Based Development**: para equipes ágeis
- **Forking Workflow**: para projetos open source
- Comparação e quando usar cada estratégia

### 6️⃣ [Como Usar o GitHub](06-como-usar-github.md)
Guia prático completo do GitHub:
- Criando conta e configurando perfil
- Criando e gerenciando repositórios
- Trabalhando com Issues e Projects
- Pull Requests: do básico ao avançado
- GitHub Actions para CI/CD
- GitHub Pages para documentação
- Colaboração em projetos open source

## 🎯 Objetivos de Aprendizagem

Ao completar este módulo, você será capaz de:

- ✅ **Compreender** os fundamentos teóricos do controle de versão
- ✅ **Explicar** como o Git funciona internamente
- ✅ **Aplicar** boas práticas de versionamento em projetos
- ✅ **Escolher** o workflow adequado para diferentes cenários
- ✅ **Utilizar** o GitHub de forma profissional
- ✅ **Colaborar** efetivamente em projetos de equipe

## 💡 Dicas de Estudo

- 📝 **Pratique regularmente**: use Git em todos os seus projetos
- 🔍 **Explore o histórico**: use `git log`, `git blame` para entender mudanças
- 🌿 **Experimente branches**: crie branches de teste sem medo
- 🤝 **Colabore**: participe de projetos open source
- 📚 **Leia código**: veja como projetos famosos usam Git

## 🎓 Exercícios Práticos Recomendados

1. **Básico**: Crie um repositório, faça commits, crie branches
2. **Intermediário**: Simule um projeto com Git Flow
3. **Avançado**: Configure GitHub Actions e automatize deploys
4. **Colaborativo**: Contribua para um projeto open source real
