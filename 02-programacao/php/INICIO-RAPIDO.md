# 🚀 Início Rápido - PHP

**Bem-vindo ao curso de PHP!** Este guia vai te ajudar a começar rapidamente.

## ⚡ Setup em 5 Minutos

1. **Instale o PHP**: Siga o [Guia de Instalação](INSTALACAO.md)
2. **Teste a instalação**:
   ```bash
   php --version
   ```
3. **Execute seu primeiro exemplo**:
   ```bash
   cd programming/php/01-conceitos-php/01/
   php 01-ola-mundo.php
   ```
