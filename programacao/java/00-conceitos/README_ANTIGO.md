# Conceitos Fundamentais de Java

Esta seção apresenta os conceitos mais básicos e fundamentais da linguagem Java, fornecendo a base necessária para começar a programar.

## 📖 Conteúdo

### [00 - Hello World](00_hello/)
Seu primeiro programa em Java - compreendendo a estrutura básica de uma aplicação Java.

**Conceitos abordados:**
- Estrutura básica de uma classe Java
- Método `main()` e ponto de entrada da aplicação
- Comando `System.out.println()`
- Compilação e execução de programas Java

### [01 - Tipos de Dados](01_Tipos%20de%20dados/)
Tipos primitivos da linguagem Java e manipulação básica de dados.

**Conceitos abordados:**
- Tipos primitivos: `int`, `float`, `double`, `char`, `boolean`
- Classe `String` para manipulação de texto
- Declaração e inicialização de variáveis
- Conversões entre tipos de dados
- Escopo de variáveis

### [02 - Controle de Fluxo (Condicionais)](02_Controle%20de%20Fluxo%20%28if%29/)
Estruturas condicionais para controlar o fluxo de execução do programa.

**Conceitos abordados:**
- Estrutura `if` e `else`
- Condicionais aninhadas
- Operadores relacionais e lógicos
- Estrutura `switch-case`
- Boas práticas em estruturas condicionais

### [03 - Controle de Fluxo (Repetição)](03_Controle%20de%20Fluxo%20%28repeticao%29/)
Estruturas de repetição para executar código múltiplas vezes.

**Conceitos abordados:**
- Loop `for` e suas variações
- Loop `while` e `do-while`
- Controle de loops com `break` e `continue`
- Loops aninhados
- Quando usar cada tipo de loop

### [04 - Exceções](04_excecoes/)
Tratamento de erros e exceções para criar programas mais robustos.

**Conceitos abordados:**
- Conceito de exceções em Java
- Blocos `try-catch-finally`
- Tipos de exceções (checked e unchecked)
- Propagação de exceções com `throws`
- Criação de exceções personalizadas

### [Exercícios](exercicios/)
Exercícios práticos para consolidar os conceitos aprendidos.

**Atividades incluídas:**
- Exercícios de lógica de programação
- Problemas práticos usando conceitos fundamentais
- Desafios de implementação

## 🎯 Objetivos de Aprendizado

Ao completar esta seção, você será capaz de:
- ✅ Criar e executar programas Java básicos
- ✅ Trabalhar com diferentes tipos de dados primitivos
- ✅ Utilizar estruturas condicionais para controlar a execução
- ✅ Implementar loops para repetição de código
- ✅ Tratar exceções de forma adequada
- ✅ Resolver problemas básicos de programação

## 🚀 Como Estudar

1. **Siga a ordem numérica**: Os conceitos são apresentados em ordem progressiva
2. **Execute os exemplos**: Compile e execute todos os códigos de exemplo
3. **Experimente**: Modifique os códigos para ver como se comportam
4. **Pratique**: Resolva os exercícios propostos em cada seção
5. **Teste seu conhecimento**: Crie seus próprios programas usando os conceitos

## 📋 Pré-requisitos

- Java JDK 8 ou superior instalado
- Editor de texto ou IDE (recomendado: VSCode, IntelliJ, Eclipse)
- Conhecimento básico de lógica de programação (desejável)

## 🔧 Como Executar os Exemplos

```bash
# Navegar até o diretório do exemplo
cd "00_hello"

# Compilar o arquivo Java
javac HelloWorld.java

# Executar o programa
java HelloWorld
```
