# Fundamentos de Java

Esta seção cobre os conceitos fundamentais da linguagem Java, essenciais para qualquer programador iniciante.

## 📖 Conteúdo

### [01 - Hello World](01-hello-world/)
Seu primeiro programa em Java - entendendo a estrutura básica de uma aplicação.

### [02 - Tipos de Dados](02-tipos-dados/)
Tipos primitivos, classes wrapper, declaração de variáveis e conversões de tipos.

### [03 - Operadores](03-operadores/)
Operadores aritméticos, relacionais, lógicos, de atribuição e bitwise.

### [04 - Controle de Fluxo](04-controle-fluxo/)
Estruturas condicionais (if, else, switch) e loops (for, while, do-while).

### [05 - Tratamento de Exceções](05-tratamento-excecoes/)
Try-catch, finally, throws e criação de exceções personalizadas.

## 🎯 Objetivos de Aprendizado

Ao completar esta seção, você será capaz de:
- ✅ Escrever e executar programas Java básicos
- ✅ Trabalhar com diferentes tipos de dados
- ✅ Usar operadores para manipular dados
- ✅ Controlar o fluxo de execução do programa
- ✅ Tratar erros e exceções adequadamente

## 🚀 Como Estudar

1. **Sequência**: Siga a ordem numérica das pastas
2. **Prática**: Execute todos os exemplos
3. **Experimente**: Modifique o código para ver o que acontece
4. **Exercite**: Faça os exercícios propostos
