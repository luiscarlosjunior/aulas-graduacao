# 🔧 PL/SQL - Linguagem de Procedimento Oracle

> Domine a programação em banco de dados Oracle com PL/SQL

Esta área contém material completo sobre PL/SQL (Procedural Language/SQL), a linguagem de programação procedural da Oracle que estende o SQL padrão.

## 📚 Estrutura do Conteúdo

### 📖 [Introdução ao PL/SQL](introducao.md)
Conceitos fundamentais e visão geral da linguagem PL/SQL.

### 📘 [SQL Básico](SQLBasico.md)
Fundamentos de SQL necessários antes de começar com PL/SQL.

---

## 🎯 Módulos de Aprendizado

### 1️⃣ [Conceitos SQL - Revisão](01-conceito-sql/)
**🎓 Nível: Iniciante | ⏱️ Duração: 1-2 semanas**

Revisão dos conceitos fundamentais de SQL necessários para PL/SQL:
- Criação de tabelas e inserção de dados
- Comandos DDL (DROP, ALTER)
- Consultas com WHERE
- JOINs básicos
- Resumo de comandos SQL

**📁 Conteúdo:**
- `Aula 01/` - Fundamentos SQL
- `Aula 02/` - Manipulação de dados
- `Aula 03/` - Consultas avançadas
- `Banco de dados/` - Scripts de criação de banco de dados

**🎯 Ideal para**: Quem precisa revisar SQL antes de começar PL/SQL.

---

### 2️⃣ [Conceitos PL/SQL](02-conceito-plsql/)
**🎓 Nível: Intermediário a Avançado | ⏱️ Duração: 6-8 semanas**

Conteúdo completo de PL/SQL organizado por aulas:

#### 📅 Aula 04 - Introdução ao PL/SQL
- Estrutura básica de blocos PL/SQL
- Variáveis e tipos de dados
- Exercícios corrigidos e exemplos práticos

#### 📅 Aula 05 - Manipulação de Dados
- Manipulação de strings
- Comandos PL/SQL básicos
- Operações com dados

#### 📅 Aula 06 - Estruturas de Controle
- Entrada de dados do usuário
- Estruturas de repetição (LOOP, WHILE, FOR)
- Estruturas condicionais (IF-THEN-ELSE, CASE)
- Exemplos práticos

#### 📅 Aula 07 - Estruturas Avançadas
- Coleções (VARRAY, TABLE, RECORD)
- Etiquetas e comando GOTO
- Manipulação de estruturas complexas

#### 📅 Aula 08 - Cursores
- Cursores implícitos e explícitos
- Manipulação de resultados de consultas
- Atributos de cursores (%FOUND, %NOTFOUND, %ROWCOUNT)
- Exemplos práticos com banco de dados

#### 📅 Aula 09 - Tratamento de Exceções
- Exceções predefinidas
- Exceções definidas pelo usuário
- Blocos de tratamento de erros
- Boas práticas

#### 📅 Aula 10 - Procedures e Functions
- Criação de procedimentos armazenados
- Criação de funções
- Parâmetros (IN, OUT, IN OUT)
- Diferenças entre procedures e functions

#### 📅 Aula 11 - Packages
- Conceito de packages
- Criação de especificações e corpos
- Organização de código
- Exemplos práticos

#### 📅 Aula 12 - Triggers
- Triggers de linha e de comando
- Triggers BEFORE e AFTER
- Triggers de eventos do sistema
- Casos de uso práticos

#### 📅 Aula 13 - Tópicos Avançados
- Otimização de código PL/SQL
- Boas práticas de programação
- Revisão geral

**🎯 Ideal para**: Desenvolvedores que querem dominar PL/SQL completamente.

---

### 3️⃣ [Curso Completo em Inglês](03-curso-completo-ingles/)
**🎓 Nível: Todos os Níveis | ⏱️ Duração: 8-12 semanas**

Material completo em inglês dividido em dois cursos:

#### 📚 PL/SQL Fundamentals I
Fundamentos da linguagem PL/SQL:
- **Lesson 3**: Language Features
- **Lesson 4**: Declare Clause (declaração de variáveis)
- **Lesson 5**: Begin Clause (lógica e estruturas de controle)
  - 5a: Data Manipulation
  - 5b-5c: SQL DML e SELECT
  - 5d-5e: SELECT e Exceptions
  - 5f: Sequences
  - 5g-5h: Logic Control e GOTO
  - 5i-5l: Loops (indefinite, conditional, nested)
  - 5m-5n: IF-THEN-ELSE e CASE
- **Lesson 6**: Exception Clause (tratamento de exceções)
  - User-Defined Exceptions
  - SQLCODE e SQLERRM
  - Implicit Cursor
  - User-Defined Events
- **Lesson 7**: Explicit Cursors (cursores explícitos)
  - CURSOR Examples e Attributes
  - Extended Techniques (Parameters, For...Loop)
- **Lesson 8**: Nested Blocks (blocos aninhados)
  - Global vs Local variables
- **Lesson 9**: Declared Subprograms

#### 📚 PL/SQL Fundamentals II
Tópicos avançados de PL/SQL:
- **Lesson 1**: Course Setup
- **Lesson 2**: Program Units
- **Lesson 3**: Stored Procedures and Functions
- **Lesson 4**: Maintain Stored Procs and Functions
- **Lesson 5**: Create and Maintain Packages
- **Lesson 6**: Advanced Cursor Techniques
- **Lesson 7**: System Supplied Packages
- **Lesson 8**: Database Triggers
- **Lesson 9**: Maintain Triggers
- **Lesson 10**: System Event Triggers

**🎯 Ideal para**: Profissionais que preferem material em inglês e querem certificação Oracle.

## 🛤️ Trilhas de Aprendizado Recomendadas

### 🌟 Trilha Completa (Iniciante ao Avançado)
**Para quem quer dominar PL/SQL completamente:**
1. SQL Básico - Revisar fundamentos (1 semana)
2. Conceitos SQL - Módulo 01 (1 semana)
3. Conceitos PL/SQL - Aulas 04-13 (6-8 semanas)
4. Curso Completo em Inglês (opcional para aprofundamento)

**Total estimado: 8-10 semanas**

### 🚀 Trilha Rápida (Essencial)
**Para quem precisa de conhecimento essencial rapidamente:**
1. Introdução ao PL/SQL (1 dia)
2. Conceitos PL/SQL - Aulas 04, 06, 10 (2 semanas)
3. Praticar com exemplos (1 semana)

**Total estimado: 3 semanas**

### 🎯 Trilha DBA (Administração)
**Para DBAs focados em manutenção:**
1. SQL Básico - Revisão (1 semana)
2. Conceitos PL/SQL - Aulas 08, 10, 11, 12 (4 semanas)
3. PL/SQL Fundamentals II - Lessons 3-10 (4 semanas)

**Total estimado: 9 semanas**
