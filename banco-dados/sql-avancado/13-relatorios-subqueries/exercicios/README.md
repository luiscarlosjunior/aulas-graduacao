# Exercícios - Módulo 13: Relatórios com Subqueries

Pratique subconsultas simples e correlacionadas.

## Exercício 2: Operadores EXISTS e IN

## Exercício 4: Common Table Expressions
Use WITH para criar consultas mais legíveis e eficientes.

## Exercício 5: Sistema de Recomendações
